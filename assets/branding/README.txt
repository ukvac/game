CHANGE THE CHECKOUT LOGO HERE
=============================

Both checkout pages use this one file:

    assets/branding/checkout-logo.svg

Easiest method
--------------
Replace checkout-logo.svg with your own SVG and keep exactly the same filename.
You do not need to edit either HTML page.

Recommended format
------------------
- SVG with a transparent background
- Wide/horizontal logo
- Approximately 356 x 88 pixels, or the same aspect ratio

Using PNG or WebP instead
-------------------------
1. Put the new file in this branding folder.
2. Change the logo path in checkout.html and payment.html.
3. Update the image alt text in both files to your organisation's name.

The displayed size is controlled by the .checkout-logo rules in
assets/styles.css.
